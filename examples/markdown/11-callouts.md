# Callouts and headings

Ordinary body text should be visually different from this page's headings.

## Helpful information

> [!NOTE]
> Notes explain useful context. Try [the Rust book](https://doc.rust-lang.org/book/).

> [!TIP]
> Drag rendered text to select it, then press **Ctrl+C**.
> Click a link to copy its URL; right-click for text or URL.

### Things to remember

> [!IMPORTANT]
> View mode stays read-only while selecting text.
>
> - Switch modes deliberately from the keyboard or options menu.
> - Code and diagram layouts scroll horizontally when needed.

#### Before proceeding

> [!WARNING]
> This is sample content, not a request to change your files.

##### Potential consequences

> [!CAUTION]
> The terminal approximates diagram geometry; it does not execute embedded code.

###### Smallest heading

> An ordinary quote, without an alert label.
>
> A second paragraph with **emphasis** and `inline code`.
